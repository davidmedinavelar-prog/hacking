🧠 Atelier algo

Chaque jour, un problème de hacker à résoudre. Les vrais développeurs ne commencent jamais par taper du code : ils réfléchissent d'abord.

  1. Comprendre : résous le problème à la main sur 2 ou 3 exemples.
  2. Algorithme : écris les étapes en français, une par ligne.
  3. Coder : traduis chaque ligne en JavaScript dans atelier.js.
  4. Tester : lis les ❌, trouve pourquoi, corrige. Recommence !

⚠️ atelier.js contient une erreur
